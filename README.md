# 单词排查器 · WordDrill

一个在浏览器本地运行的背单词工具。它的目标不是应试，而是**练习与排查未掌握的单词**：给出一个单词，从 4 个带词性的中文释义里选出正确项，再看自己到底错在哪一类。

全部数据只保存在你自己的浏览器里，不联网、不上传。

## 功能

- **6 选项题型**：4 个中文释义（每个带词性，如 `v. 取消，撤销`）+「以上都不对」+「不知道」
- **「以上都不对」有时是正确答案**：按比例生成「四个释义全错」的题，唯一正解是它；比例可调（默认 12%）
- **干扰项来自形态相近的单词**：如 confuse → confine / confess / confide，且强制过滤语义相关项（释义重叠、同词干变形都不会出现）
- **错项溯源**：判分后每个错误选项标注它实际属于哪个单词（如 `n. ← cancer`）；「以上都不对」的否定题会当场给出该词的正确释义
- **四色判定**：绿 = 全对、黄 = 漏选、蓝 = 多选、红 = 错选；「不知道」记为未掌握但不判错
- **多义项不定项**：单词有 2 个以上义项时，正确项可能有多个，需全部选对
- **回退与跳过**：回退会撤销上一题统计并恢复同一组选项；跳过计入未掌握
- **每题限时**：可关闭或设为 5/10/15/20/30 秒及自定义；切到后台自动暂停
- **考察顺序**：顺序（按词表原序）或随机（每轮重新洗牌）
- **自动保存**：答题、回退、改设置后自动落盘，刷新可继续上次进度
- **存档 JSON 导入导出**：支持逐词较新合并 / 整份覆盖
- **未掌握词表导出 TXT**：只导出**选错过且尚未掌握**的词（错选/漏选/多选；只标记「不知道」、超时、跳过的不算），纯单词 / 带中文 / 带词性与中文，可按错误次数或字母序
- **清除数据**：需输入「清除」二次确认

## 快速开始

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install

# 1) 准备词库：把 qwerty-dicts/ 放在项目根目录（见下节）
# 2) 构建词库数据，生成 public/data（约 28MB）
pnpm build:data

# 3) 开发模式
pnpm dev          # http://127.0.0.1:5178

# 或者构建后预览
pnpm build
pnpm preview      # http://127.0.0.1:5178
```

> `public/data/` 与原始词库都不进仓库（体积与版权原因），首次使用必须执行一次 `pnpm build:data`。

## 词库

项目使用 `qwerty-dicts/` 目录下的英汉词表（来自 qwerty-learner 词库集合），构建脚本会：

- 剔除日语、哈萨克语、德语、印尼语与编程术语等非英汉词表
- 切分 `vt.得到,抓住vi.成为n.生殖` 这类多词性混排、清洗 `时态:` `名 词:` 等变形噪声
- 通过词性标注率高的词典做**跨词典词性对齐**（CET-4 等无词性词表也能显示 `v.` / `n.`）
- 按单词序列去重（重复词表合并为一条 alias）
- 生成 23k 词的**干扰词池**（只收锚定语料中出现的英文单词，杜绝罗马字与代码标识符）

产物：

| 文件 | 内容 |
| --- | --- |
| `public/data/manifest.json` | 词表清单（标题/分类/词数/词性覆盖率） |
| `public/data/dict/<id>.json` | 规范化后的单词与义项 |
| `public/data/pool.json` | 干扰词池 |
| `reports/build-report.json` | 构建报告（收录/跳过原因） |

## 判色规则

| 情况 | 结果 | 颜色 |
| --- | --- | --- |
| 选中全部正确义项、未选错误项 | 全对 | 绿 |
| 只选了部分正确义项 | 漏选 | 黄 |
| 正确义项选全但多选了错误项 | 多选 | 蓝 |
| 其余（选错 / 漏选且错选） | 错选 | 红 |
| 点「不知道」 | 未掌握 | 灰 |
| 限时到 | 超时 | 红 |

连续 2 次「全对」即视为掌握；错、漏、多、超时、跳过都会清零连击。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `1`–`4` | 选择对应释义 |
| `5` / `N` | 以上都不对 |
| `0` / `D` | 不知道 |
| `Enter` / `Space` | 提交；已出结果时进入下一题 |
| `←` | 回退（撤销上一题并重做） |
| `→` | 跳过 |

## 数据与隐私

- 学习记录、设置、本轮进度保存在浏览器 IndexedDB（库名 `worddrill`）
- 干扰词池首次加载后缓存，刷新不再重复下载
- 换浏览器 / 清缓存前请先在「存档」页导出 JSON

## 目录结构

```
src/
├─ engine/     出题（干扰项、判定）、判分、队列、确定性随机
├─ store/      状态机（appStore）、持久化、导入导出
├─ screens/    练习台 / 答题 / 结算 / 设置 / 存档
├─ components/ 选项卡、印章、倒计时环
├─ lib/        类型契约、结果样式、下载与音效
├─ data/       词表、干扰词池加载
└─ styles/     设计令牌与全部样式
scripts/
├─ build-data.mjs   词库 → public/data
└─ screenshot.mjs   用 Playwright 截图
tests/
├─ unit/       Vitest：分词、出题不变量、判分矩阵、队列、持久化、导入导出
└─ e2e/        Playwright：完整练习流程、回退/跳过、设置持久化、导出、超时
```

## 常用命令

```bash
pnpm typecheck     # tsc --noEmit
pnpm test          # 43 个单元测试
pnpm e2e           # 5 个端到端测试（需先装浏览器：pnpm exec playwright install chromium）

pnpm build:data:force
```

## 已知限制

- 语义无关过滤基于中文释义的分句重合、二字组重合与词干判断，**不能保证 100%** 排除近义干扰；实际抽样中未发现明显泄漏
- 词性由跨词典对齐推断，个别词可能缺失（缺失时该选项不显示词性）
- 词库版权归 qwerty-dicts 原作者，本项目仅作本地个人学习使用
- 干扰项优先选形态相近的词；若某词在池中没有足够近邻，会退化为较弱的相似词或无关词（仍保证语义无关）
